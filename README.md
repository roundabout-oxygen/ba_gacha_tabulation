# Gacha Tabulation (v1.0.1)

『ブルーアーカイブ（ブルアカ）』のガチャ記録・統計集計ウェブアプリケーションです。  
Googleスプレッドシートとの自動巡回同期、確率収束グラフ、生徒図鑑、最大ハマり計算、ガチャ運評価などの機能を備えています。

**🔗 公開URL（GitHub Pages設定後）:**  
`https://roundabout-oxygen.github.io/ba_gacha_tabulation/`

---

## 🌟 主な機能

1. **📊 統計ダッシュボード**
   - 総ガチャ回数・青輝石消費数の自動集計
   - 通常枠（3%）とフェス枠（6%）ごとの実測確率・期待値・引き数
   - ピックアップ実測確率と理論期待値の比較
   - 100連目50%枠の勝率集計
   - ★3 確率収束＆相対誤差マトリクス折れ線グラフ（Chart.js）
   - ☆3なし最大ハマり（3%・6%枠のみ対象で厳密集計）
   - 期待値との過不足（上振れ/下振れの人数学的ブレ）
   - 天井到達（200連）と総ガチャ回数の比較分析

2. **🎓 排出☆3生徒図鑑（横10列高密度レイアウト）**
   - ピックアップ生徒: 🟡 **ゴールドイエロー枠**
   - 新規獲得生徒: 🔴 **レッド枠**
   - 50%枠獲得生徒: 🟢 **グリーン枠**
   - 100%天井交換生徒: ⚫ **ブラック枠（ラベル「交換」）**
   - その他被り生徒: ⚪ **グレー枠**
   - 重複獲得時の「〇回目」凸数バッジ（アイコン右下に美しく重ねて表示）
   - 同一10連内での獲得順を正しく判定する時系列ソート

3. **🌐 Googleスプレッドシート自動巡回連携**
   - スプレッドシートの閲覧URL（共有リンク）を登録すると、**アプリ起動時に自動で最新データを巡回・反映**。
   - シート指定あり（`#gid=...`）でも、スプレッドシート全体のURLのみでも自動解析対応。
   - **完全クライアント動作・プライバシー保護**: ガチャデータは外部サーバーに送信・保管されず、お使いの端末ブラウザ内（`localStorage`）だけで安全に管理されます。

4. **🔄 キャラアイコン月1回自動更新 (GitHub Actions) ＆ 手動巡回**
   - **GitHub Actions**: 毎月1日午前0時(UTC)に攻略Wiki（`キャラクター一覧`）から最新の生徒名・アイコンURLを自動取得し、リポジトリ内 `data/student_icons.json` を自動更新。
   - **アプリ内手動巡回**: 生徒図鑑の「🔄 アイコン取得」ボタンを押すと、「〇時間前に巡回を行いました。サイト巡回を実施しますか？」の確認ポップアップが表示され、即座にサイトを巡回して最新アイコンを適用。

5. **📄 スプレッドシート作成サンプル ＆ テンプレート**
   - ワンクリックでクリップボードにサンプルデータ（TSV）をコピー
   - Googleスプレッドシートに直接インポート可能な `blue_archive_gacha_template.csv` ダウンロード機能
   - 各列の入力ルール（累計、引、☆3、pick、新、既、生徒名、pick率）の図解ガイド

## 🚀 GitHub Pages へのデプロイ手順

本リポジトリは静的Webアプリ（HTML / CSS / JavaScript）で構成されているため、GitHub Pages で即座に無料公開できます。

1. GitHub リポジトリ（`https://github.com/roundabout-oxygen/ba_gacha_tabulation`）を開きます。
2. 上部メニューの **[Settings]**（設定）をクリックします。
3. 左側メニューの **[Pages]** をクリックします。
4. **[Build and deployment]** セクションで：
   - **Source**: `Deploy from a branch` を選択
   - **Branch**: `main` ブランチ、フォルダは `/ (root)` を選択して **[Save]** をクリック。
5. 1〜2分後、発行されたURL（`https://roundabout-oxygen.github.io/ba_gacha_tabulation/`）にアクセスすれば、世界中どこからでもPC・スマホで利用可能になります！
